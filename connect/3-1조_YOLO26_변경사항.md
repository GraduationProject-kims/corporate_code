# 3-1조 YOLO26 교체 (10/30)

기존 기능(판정 4.1~4.11, 실시간 서버, 녹화 평가, 기록 형식, 클래스 모드, 사이트 전송)은 **전부 그대로**.
바뀐 건 judge.py의 **모델 두 개**뿐.

| | 전 | 후 |
|---|---|---|
| 물체 탐지 | yolo11n.pt | **yolo26s.pt** (n보다 정확, 처음 실행 때 자동 다운로드) |
| 거리(depth) | Depth Anything V2 Metric Indoor Small (transformers) | **yolo26n-depth.pt** (ultralytics, 미터 단위) |

왜: 10/16·10/19 실시간 기록에서 depth 한 번에 약 430 ms(맥 mps), YOLO는 15 ms. 지연 대부분이 depth.

## 파일

| 파일 | 무엇 |
|---|---|
| `judge.py` (수정) | 설정에 `DEPTH_BACKEND`·`DEPTH_IMG_SIZE`·`DEPTH_COREML` 추가, `load_models`·`depth_map`만 교체. 판정 함수·상수 그대로 |
| `tools/compare_depth.py` (추가) | 같은 영상에서 depth 모델끼리 속도·거리 비교 (정지 촬영이면 실제 거리 대비 오차) |
| `environment.yml` (수정) | ultralytics 8.4.104 이상 (서버 맥은 이미 8.4.175라 설치 필요 없음) |

server.py, run_model.py, live_record.py는 **안 고침**. 실행 명령도 그대로.

## 실행

```bash
# 그대로 (YOLO26)
RUNNER=내이름 uvicorn server:app --host 0.0.0.0 --port 8001
python run_model.py --video 1019_front_01.mp4 --runner 내이름

# 예전 모델로 (베이스라인 재현·비교) — 코드 안 고치고 앞에만 붙임
DEPTH_BACKEND=dav2 YOLO_MODEL=yolo11n.pt python run_model.py --video ... --runner 내이름

# 맥 Neural Engine으로 depth (더 빠를 수 있음, 처음 한 번 변환)
DEPTH_COREML=1 RUNNER=내이름 uvicorn server:app --host 0.0.0.0 --port 8001

# 다른 크기 시험
DEPTH_MODEL=yolo26s-depth.pt ...   /   DEPTH_IMG_SIZE=640 ...   /   YOLO_MODEL=yolo26n.pt ...
```

어떤 모델·크기로 돌렸는지는 run_meta.json `pipeline`의 `yolo_weights`, `depth_backend`, `depth_model`, `depth_imgsz`, `depth_coreml`에 남음.

## 꼭 할 것 (바꾸기 전에)

1. **맥에서 속도 재기**: 속도 수치는 NVIDIA 기준이라 맥에서는 직접 확인해야 함
   `python tools/compare_depth.py --video 1019_bottle_01.mp4`
2. **거리 정확도 재기**: 정면 1·2·3·4 m 정지 촬영 영상으로
   `python tools/compare_depth.py --video 1017_d2m_01.mp4 --gt_m 2.0`
   → 2 m 근처 오차가 DA V2보다 크면 `DEPTH_MODEL=yolo26s-depth.pt`로 다시 비교. 한쪽으로 일정하게 치우치면 `DEPTH_SCALE` 보정
3. **DEPTH_SCALE**은 모델마다 다름. 예전 모델 기준으로 맞춘 값이 있었다면 YOLO26으로 다시 재야 함 (지금 기본 1.0)
4. 7주 베이스라인 숫자는 예전 모델(DEPTH_BACKEND=dav2, yolo11n) 결과. 비교표에는 두 설정을 같은 영상으로 돌린 값을 나란히 쓸 것

## 알아둘 것

- 폼보드 간판은 COCO 클래스가 아니라서 YOLO(11이든 26이든)가 박스로 잘 못 잡음. 간판 경고는 지금처럼 주로 **경로 depth(DEPTH)** 로 뜸. "물체 탐지 정확도"를 올리려면 간판 사진으로 파인튜닝이 필요함
- YOLO26-depth 공개 가중치는 768 입력으로 학습됨. 줄이면 빨라지지만 거리 오차가 늘 수 있으니 compare_depth.py로 확인하고 바꿀 것
- 라이선스: YOLO26(탐지·depth) AGPL-3.0. 학교 과제는 문제없음. 기업이 가져다 쓸 때는 따로 확인
- CoreML(`DEPTH_COREML=1`)은 맥에서만. 변환 실패하면 자동으로 PyTorch(mps)로 돌아감
