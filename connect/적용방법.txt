3-1조 서버 통합 — 적용 방법 (10/16)

이 server.py는 지금 맥북에서 쓰던 server.py(장치 자동 선택 + 시연 사이트 live_mirror 연결)를
그대로 바탕으로, 판정 부분만 연수 코드와 같은 judge.py로 바꾼 것.
- 폰 앱은 안 고침. 회신 형식이 같아서 그대로 연결됨
- 시연 사이트 전송(live_mirror)도 그대로 + 판정 결과(judge: 경고·방향·모터)가 같이 감
- 새로 설치할 패키지 없음

──────────────────────────────
1. 넣을 위치
──────────────────────────────
지금 서버를 켜는 폴더 (server.py, live_mirror.py, yolo11n.pt가 있는 곳)

  server/                 ← 여기
  ├─ server.py            ← 교체 (덮어쓰기)
  ├─ judge.py             ← 새로 넣기
  ├─ live_record.py       ← 새로 넣기
  ├─ run_model.py         ← 새로 넣기 (녹화 영상 평가용)
  ├─ run_model.md         ← 새로 넣기
  ├─ 3-1조_변경사항.md     ← 새로 넣기
  ├─ tools/               ← 폴더째 넣기
  ├─ live_mirror.py       (원래 있던 것 그대로 — 지우면 안 됨)
  └─ yolo11n.pt 등        (원래 있던 것 그대로)

이 압축 파일의 server 폴더 안 내용물을 위 폴더에 그대로 복사하면 됨.

──────────────────────────────
2. 순서
──────────────────────────────
(1) 돌아가는 서버 끄기: 서버 터미널에서 Ctrl+C
(2) 백업:  cp server.py server_orig.py
(3) 이 압축 파일의 server 폴더 안 파일들을 복사 (server.py는 덮어쓰기)
(4) 실행 — 원래 명령 앞에 이름만 붙임 (포트는 지금 쓰던 번호 그대로)
    RUNNER=이름 uvicorn server:app --host 0.0.0.0 --port 8001

──────────────────────────────
3. 잘 됐는지 확인
──────────────────────────────
- 터미널: "모델 로드 완료 (device=mps, ...)"
- 서버 창: 초록 경로 사각형 + "OBSTACLE 2.85m (DEPTH)" 같은 글자
- 장애물·벽에 3 m 안으로 다가가면 사각형 빨강 + "-> NECK / LEFT / RIGHT"
- 터미널 줄 끝에 "장애물=2.08m ⚠ 정면→neck" 같은 표시
- 시연 사이트에 영상이 전처럼 나오는지
- 폰 화면 박스도 전처럼 나오는지
  (폰 진동·소리는 아직 앱 안의 원래 판정으로 울림. 정상)

기록 시험:
- 서버 터미널에 1016_test_01 입력 + Enter → 조금 걷기 → 그냥 Enter
- runs/이름/1016_test_01_날짜_시간/ 에 frames.csv, latency.csv, summary.json 생기면 성공

──────────────────────────────
4. 되돌리기
──────────────────────────────
Ctrl+C → cp server_orig.py server.py → 원래 명령으로 다시 실행

──────────────────────────────
참고: 바뀐 설정
──────────────────────────────
- YOLO 신뢰도 0.25 → 0.4, 입력 크기 480 → 416 (녹화 평가와 같게, judge.py에서 설정)
- 받은 프레임을 폭 640으로 줄여서 계산 (녹화 평가와 같게). 폰에 보내는 좌표는 원본 크기로 되돌림
- 사이트에 보내는 좌표는 화면 이미지(640 폭)에 맞춤

──────────────────────────────
5. 베이스라인(시스템 기본 성능) 뽑기
──────────────────────────────
(1) 서버 켜고 평소처럼 연결해서 1~2분 기록 (지연·속도용)
    서버 터미널: 1017_live_01 Enter → 걷거나 둘러보기 → Enter
(2) 정지 촬영: 장애물을 정면 1·2·3·4 m에 두고 각각 10초씩 기록
    시행ID에 거리를 꼭 넣기: 1017_d1m_01, 1017_d2m_01, 1017_d3m_01, 1017_d4m_01
    → 서버 창에서 원(가장 가까운 점)이 장애물 위에 있는지 확인 (바닥·벽이면 메모)
(3) 표 만들기:  python tools/baseline_report.py runs/이름
    → 화면에 표가 나오고 runs/이름/baseline_report.md 로 저장됨
(4) 폰 쪽 지연은 Android Studio Logcat에서 tag:NET_METRICS (rtt / server / network) 값 적기

──────────────────────────────
6. 물병 모드 (클래스 기반 시험)
──────────────────────────────
실행 명령 앞에 TARGET_LABELS=bottle 만 붙이면, YOLO가 물병(bottle)으로 잡은 박스만 장애물로 봄
(깊이로 통로를 보는 원래 판정은 꺼짐. 거리는 물병 박스 영역의 깊이 값)
  TARGET_LABELS=bottle RUNNER=이름 uvicorn server:app --host 0.0.0.0 --port 8001
녹화 영상도 같은 모드로:
  TARGET_LABELS=bottle python run_model.py --video 1019_front_01.mp4 --runner 이름
- 서버 시작할 때 "판정 모드: 클래스 bottle 박스만"이 뜨면 적용된 것
- 안 붙이면 원래 깊이 기반 판정 (기본)
- 어느 모드로 돌렸는지는 run_meta.json의 TARGET_LABELS에 기록됨

──────────────────────────────
7. 시연 사이트 (v5에서 바뀜)
──────────────────────────────
- 사이트로는 원래 맥북 버전과 똑같은 형식으로 보냄 (원본 크기 이미지, 원래 항목만)
- 서버 켜고 폰이 연결되면 터미널에 "[사이트] 첫 프레임 넘김 (이미지 ...)"이 한 번 뜸
- 사이트에도 우리 판정(경고·방향·모터)을 보내려면 실행 명령 앞에 SITE_JUDGE=1 추가
    SITE_JUDGE=1 RUNNER=이름 uvicorn server:app --host 0.0.0.0 --port 8001
- 그래도 사이트에 영상이 안 나오면:
  (1) cp server_orig.py server.py 로 원래 코드로 켜서 사이트가 나오는지 확인
      → 원래 코드로도 안 나오면 코드 문제가 아니라 사이트·네트워크(주소, 같은 와이파이 등) 문제
  (2) 원래 코드로는 나오고 이걸로만 안 나오면 live_mirror.py 파일과 터미널 화면을 지은이한테 보내기
- live_mirror.py는 zip에 없음. 서버 폴더에 원래 있던 걸 그대로 둬야 함 (폴더를 통째로 바꾸지 말 것)
